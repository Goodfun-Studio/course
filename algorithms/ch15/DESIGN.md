## 核心动画重点（beat 4, UI 5/12）

### 图结构（7个节点树形）
```
        A
       / \
      B   C
     / \ / \
    D  E F  G
```
- **节点**: A(root), B/C(第一层), D/E(第二层), F/G(第三层)
- **遍历顺序**: A → B → C → D → E → F → G

### 动画要素
- **波纹扩散效果**: 节点缩放动画展示层级递进
- **队列实时显示**: 底部显示队列状态变化
  - `[A]` → `[B,C]` → `[C,D,E]` → `[D,E,F,G]` → ...
- **遍历顺序**: 顶部动态累积
- **节点状态颜色** (4种):
  - 未访问（灰色）
  - 在队列中（蓝色）
  - 当前处理（橙色）
  - 已访问（绿色）
- **边高亮**: 处理节点时其出边闪烁

### 动画规格
- tw() 调用: **47次**（要求≥25）
- 颜色种类: **4种**（要求≥4）
- 时间跨度: **41.9秒**（要求≥12）

## 颜色方案
```javascript
UNVISITED = '#95a5a6';   // 灰色（未访问）
CURRENT   = '#f39c12';   // 橙色（当前处理）
```

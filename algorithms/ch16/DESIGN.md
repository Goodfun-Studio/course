## 核心动画：dfs-demo（UI 5/13）

### 图结构（7节点树）
```
        A
       / \
      B   C
     / \ / \
    D  E F  G
```
- **遍历顺序**: A → B → D → E → C → F → G

### 动画要素
- **节点状态色**: 未访问(灰) / 正在访问(橙) / 已访问(绿) / 回溯(黄)
- **边高亮**: 正在遍历的边用红色加粗
- **调用栈**: 底部实时显示栈内容（入栈/出栈）
- **遍历顺序**: 顶部动态累积
- **回溯演示**: 从叶节点回溯到根

### 旁白标记（12个）
`example, start, a, b, d, backtrack_d, e, backtrack_e, backtrack_b, c, f, g`（+ `done`）

## 各 beat 的标记↔动画映射（示范：recursive）

narration 原文与标记：
```
先看递归实现。[[code]]代码非常简洁：...[[mark]]接下来遍历所有邻居，如果邻居
还没访问过，就递归调用自己。[[neighbors]]递归的优雅之处在于，回溯是自动的。
[[elegant]]当递归调用返回时，就自然回到了上一层，不需要手动管理栈。[[automatic]]
这是 DFS 最常见的写法，简单直观，适合大多数场景。[[common]]
```
- `code` (2.8s) → 代码区域出现
- `mark` (10.2s) → 逐行显示代码
- `neighbors` (16.8s) → 高亮 for 循环行
- `elegant` (24.5s) → "简洁优雅…" 说明文字
- `automatic` (29.8s) → 应补："递归返回时自然回到上一层" 🔧
- `common` (37.4s) → 应补："最常见的写法，适合大多数场景" 🔧

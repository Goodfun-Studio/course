# Ch26 动画与旁白脱节修复报告

## 任务概述
修复 ch26（树状数组 Fenwick Tree）的动画与旁白脱节问题。

## 问题诊断
初始验证结果显示严重的动画-旁白不同步：
- **14个beat全部比值不达标**：大部分在 0.09-0.23 之间，远低于 0.8 标准
- **11个beat覆盖率不达标**：大部分元素集中在前 20%-30%，后半段空白
- 根本原因：所有动画时长过短，无法填充旁白时长

## 修复方案
采用**比例缩放方案**（本章无 [[mark]] 标记）：
1. 对每个 beat 计算缩放因子：`factor = (dur × 0.9) / animEnd`
2. 将所有硬编码的 `t0` 值乘以该因子
3. 对使用 `let t = ...` 累加的 beat，初始值和增量也同比例缩放
4. 确保动画填充至旁白时长的 90%

### 典型示例：update-demo

**原始代码**（累加时间变量）：
```javascript
let t = 2;
tw(step1, { o: 1 }, t, 0.4);        // t=2
t += 0.6;                            // t=2.6
tw(arrow1.g, { o: 1 }, t, 0.4);     // t=2.6
t += 0.8;                            // t=3.4
```
总动画时长：~10s

**修复后**（所有时间值按 5.5× 缩放）：
```javascript
let t = 11.0;                        // 2 × 5.5
tw(step1, { o: 1 }, t, 0.4);        // t=11.0
t += 3.3;                            // 0.6 × 5.5
tw(arrow1.g, { o: 1 }, t, 0.4);     // t=14.3
t += 4.4;                            // 0.8 × 5.5
```
总动画时长：~52s，填充旁白时长 57.55s 的 90%
